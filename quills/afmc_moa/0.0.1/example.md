PURPOSE AND SCOPE: This MOA establishes the terms under which the AFETC provides thermal-vacuum chamber test support to the NEWL for the qualification of NEWL sensor payloads. It covers scheduling, test execution, data delivery and reimbursement for that support, and no other AFETC facility.

~~~
$kind: responsibilities_of_the_parties
~~~
RESPONSIBILITIES OF THE PARTIES:

- The AFETC will—
  - Schedule up to four chamber test windows per fiscal year for NEWL test articles.
  - Provide chamber operators and instrumentation technicians for each scheduled test window.
  - Deliver raw and reduced test data to the NEWL within 10 business days of test completion.
- The NEWL will—
  - Request each test window at least 60 days before its start.
  - Deliver test articles, test procedures and hazard analyses to the AFETC at least 14 days before each test window.
  - Reimburse the AFETC for the support in Attachment A.
- Both Parties will—
  - Conduct a joint safety review before each test window.
  - Protect test data in accordance with its marking.

The AFETC reserves the following thermal-vacuum chamber test windows for the NEWL in fiscal year 2027. Each window includes one day of chamber pump-down and one day of return to ambient.

- 2-13 November 2026: NEWL Sensor Block 2, thermal balance.
- 8-19 February 2027: NEWL Sensor Block 2, thermal cycling.
- 10-21 May 2027: NEWL Sensor Block 3, thermal balance.
- 9-20 August 2027: Reserved for retest.

The NEWL confirms or releases each window at least 60 days before its start. A released window returns to the AFETC schedule without charge.
