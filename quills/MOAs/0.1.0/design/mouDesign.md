# MOU Design Quill 

This document provides a guidance and requirements for creating a compliant memorandum of agreement (MOA). 

## Requirements

Please refer to MOU.pdf for the specific implementation details. 

Reference the example MOA Template.pdf for an example implementation of the required specifications.

At the end you will have a fully functioning quill 

## Validation Loop

You will use quillmark cli tool to render a completed MOA.

 Use pymupdf library to validate the quillmark output.

 Between each validation run, identify deviations from the example and the specifications in the MOU.pdf
