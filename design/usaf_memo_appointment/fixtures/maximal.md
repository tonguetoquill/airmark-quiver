The primary security manager is organizationally aligned to allow direct access to unit leadership. Assistants report directly to the primary security manager. Appointees will:

- Complete security manager training within 90 duty days of this letter.
- Conduct the annual self-inspection and semiannual security education briefings.
- Notify 673 ABW/IP 60 days prior to PCS, PCA, or separation.

Each appointee holds a security clearance equal to the highest level of classified information stored by the unit.

Point of contact for this action is Capt First M. Last, 773 LRS/CSS, 907-552-0000 or first.last@us.af.mil.
