# Chapter 15: Personal Letter Specifications
*The Tongue and Quill — AFH 33-337, 27 MAY 2015*

---

## When to Use

Use a personal letter when communication needs a personal touch, warmth, or sincerity — such as praise, condolences, or sponsorship. Keep it **brief (preferably one page)** and **avoid acronyms**. For envelopes, always use USPS abbreviations for addresses.

---

## Heading Section

### Date
- **Placement:** 1 inch from the right edge, 1.75 inches from the top of the page
- **Military/government addressees:** "Day Month Year" (e.g., *15 October 2014*) or "DD Mmm YY" (e.g., *15 Oct 14*)
- **Civilian addressees:** "Month Day, Year" (e.g., *October 15, 2014*)
- Date at time of dispatch unless the date of signature has legal significance

### Return Address
- Flush with the **left margin**, on the **second line below the date**
- Include: rank, full name, duty title, organization, complete mailing address
- **Single-spaced** lines
- Use periods after abbreviations: Mr., Ms., Mrs., Dr.
- No punctuation on the last address line except the ZIP+4 dash

### Receiver's Address
- Placed on the **third line below the return address**
- Include: title/rank, full name, complete mailing address
- **Single-spaced** lines
- Same punctuation rules as return address

### Salutation
- Placed on the **second line below the receiver's address**
- Begins with "Dear" followed by title/rank and last name
- **No punctuation** after the salutation (open punctuation style)

---

## Text of the Letter

- Starts on the **second line below the salutation**
- **Do not number paragraphs**
- **Indent** the first line of each major paragraph **0.5 inches**
- All second and subsequent lines are **flush with the left margin**
- Sub-paragraphs follow the same guidance as the official memorandum
- A one-paragraph letter with fewer than eight lines **may be double-spaced**
- Include references in the **first paragraph** (no separate references element)

---

## Closing Section

### Complimentary Close
- Use "**Sincerely**"
- Placed on the **second line below the text**
- Position: **4.5 inches from the left edge** (three spaces right of page center)
- **No punctuation** after the close

### Authority Line
- **Not used** for personal letters

### Signature Element
- Placed on the **fifth line below** the complimentary close
- **Aligned with** the complimentary close (4.5 inches from the left edge)
- Use the sender's **full signature block**

### Attachment Element
- `Attachment:` — for a single attachment
- `# Attachments:` — for two or more attachments
- Flush with the **left margin**
- On the **third line below** the signature element

### Courtesy Copy (`cc:`)
- Flush with the **left margin**
- **Second line below** the attachment element — or **third line below** the signature element if no attachment element is used
- List names or unit designators of recipients
- If sent without attachments, type "wo/Atch" after the office; circle, underline, or highlight that office on the recipient's copy

---

## General Formatting Notes

| Rule | Standard |
|------|----------|
| Envelope addresses | Use USPS abbreviations |
| Punctuation style | Open (no punctuation after salutation or complimentary close) |
| Rank in letter address | Spell out in full |
| Rank on envelope | May abbreviate |
| "U.S." / "U.N." | Written without periods: **US**, **UN** |
| Address line spacing | Single-spaced |
| Periods | Used after Mr., Ms., Mrs., Dr. |
| ZIP+4 code | Dash used; two spaces between state abbreviation and ZIP |

## Forms of Address Quick Reference

### Military Officers (Army, Air Force, Marine Corps)

| Rank | Address on Letter | Salutation |
|------|-------------------|------------|
| General, Lt General, Maj General, Brig General | (Full rank) (Full name), (Service abbrev) | Dear General (last name) |
| Colonel, Lt Colonel | (same) | Dear Colonel (last name) |
| Major | (same) | Dear Major (last name) |
| Captain | (same) | Dear Captain (last name) |
| First/Second Lieutenant | (same) | Dear Lieutenant (last name) |
| Chief Warrant Officer | (same) | Dear Mr./Miss/Ms./Mrs. (last name) |

### Air Force Enlisted

| Rank | Salutation |
|------|------------|
| Chief Master Sergeant of the AF / Chief Master Sergeant | Dear Chief (last name) |
| Senior Master Sergeant / Master Sergeant / Technical Sergeant / Staff Sergeant | Dear Sergeant (last name) |
| Senior Airman / Airman First Class / Airman / Airman Basic | Dear Airman (last name) |

### Civilian Officials

| Addressee | Salutation |
|-----------|------------|
| The President | Dear Mr./Madam President |
| The Vice President | Dear Mr./Madam Vice President |
| Cabinet Secretary | Dear Mr./Madam Secretary |
| US Senator | Dear Senator (last name) |
| US Representative | Dear Representative (last name) |
| State Governor | Dear Governor (last name) |
| Mayor | Dear Mayor (last name) |
| Federal/State Judge | Dear Judge (last name) |

> **Note:** All complimentary closes are **Sincerely**, except for the President, which uses **Respectfully yours**.
